# AI 로또 번호 생성기

역대 로또 6/45 1등 당첨번호의 패턴 분포를 따라 5게임을 생성하는 단일 페이지 앱입니다.

- 사이트: https://psh845.github.io/lotto-game
- 빌드 과정 없음. `index.html` 하나로 동작하며, 당첨번호 데이터도 이 파일 안에 들어 있습니다.

> 당첨 확률을 높여주지 않습니다. 어떤 조합이든 1등 확률은 1/8,145,060로 같습니다. 재미로만 이용해주세요.

## 번호 생성 방식

1. **패턴 분포 따라가기**: 게임마다 실제 당첨번호에서 나온 비율대로 패턴(홀짝, 저고(1~22 / 23~45), 연속번호 쌍 수, 직전 회차 이월 개수)을 하나 뽑고, 그 패턴에 맞는 조합이 나올 때까지 번호를 다시 뽑습니다.
2. **약한 번호 가중치**: 전체 회차와 최근 100회 출현 빈도를 섞어 0.85~1.15 범위로만 반영합니다. 번호별 빈도 차이는 통계적으로 무작위 수준이기 때문입니다.
3. **인기 조합 피하기**: 등간격 4개 이상(예: 5·10·15·20), 한 번호대에 6개 몰림, 직전 회차와 4개 이상 겹침, 과거 1등과 같은 조합은 제외하고, 6개 모두 31 이하인 조합은 절반만 남깁니다. 당첨 확률은 그대로이고, 당첨됐을 때 당첨금을 나눠 가질 사람만 줄어듭니다.
4. **게임 간 다양성**: 두 게임이 겹치는 번호는 최대 2개, 한 번호는 5게임에서 최대 2번까지만 씁니다.

## 당첨번호 데이터 갱신 방법

매주 토요일 추첨 후 아래 순서로 갱신합니다. Node.js 18 이상이 필요합니다.

```bash
node scripts/update-draws.js
git add index.html
git commit -m "Update draws to <회차>"
git push
```

- 스크립트는 공개 데이터셋 두 곳([uriseozz/lotto-data](https://github.com/uriseozz/lotto-data), [jeong760/lotto-data](https://github.com/jeong760/lotto-data))에서 받은 번호가 모든 회차에서 일치할 때만 `index.html`을 고칩니다. 원본 출처는 둘 다 동행복권입니다.
- 새 회차가 없으면 `이미 최신입니다`가 나오고 파일은 바뀌지 않습니다.
- 데이터셋끼리 번호가 다르거나, 받은 데이터가 현재보다 오래됐거나, 네트워크 오류가 나면 `갱신 실패: ...`를 출력하고 파일을 건드리지 않습니다. 한쪽 데이터셋이 아직 갱신되지 않았다면 교차검증된 회차까지만 반영되니, 몇 시간 뒤 다시 실행하세요.
- 푸시하면 GitHub Pages에 보통 1~2분 안에 반영됩니다.

스크립트가 고치는 곳은 `index.html`의 아래 세 부분입니다. 이 줄들의 형식을 바꾸면 스크립트가 찾지 못하니 주의하세요.

- ``const DRAW_DATA = `...`;`` (1회부터 회차 순서대로 번호 6개씩)
- `const DRAW_DATA_LATEST_DATE = "YYYY-MM-DD";`
- `<strong id="roundCount">회차</strong>`
